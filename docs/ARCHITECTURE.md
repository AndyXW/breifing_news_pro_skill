## 📦 核心组件

### 1. index.js - 主入口

**职责**:
- 解析命令行参数（edition, outputMode）
- 协调各模块执行流程
- 输出最终简报

**流程**:
```
1. 验证环境变量
2. 获取新闻（Tavily API）
3. 按板块分类
4. 生成简报（ai-analyzer.js）
5. 输出到控制台/飞书
```

---

### 2. config.js - 配置管理

**职责**:
- 从环境变量读取配置
- 定义 Tavily API 参数
- 定义 6 大搜索模块

**配置项**:
```javascript
{
  TAVILY_API_KEY: process.env.TAVILY_API_KEY,
  FEISHU: {
    USER_ID: process.env.FEISHU_USER_ID,
    MAX_WORDS: 1500
  },
  TAVILY: {
    SEARCH_DEPTH: 'advanced',
    TIME_RANGE: 'day',
    MAX_RESULTS: 15
  }
}
```

---

### 3. news-fetcher.js - 新闻获取

**职责**:
- 从 Tavily API 获取新闻
- 支持 6 大搜索模块
- 新闻去重和分类

**搜索模块**:
1. 宏观政策（15 条）
2. 晚间公告（15 条）
3. 机构复盘（15 条）
4. A 股收评（15 条）
5. 行业深度（15 条）

**晚间版特殊处理**:
- 跳过外盘映射模块（外盘还没开）

---

### 4. news-processor.js - 新闻处理

**职责**:
- 标题清理（去除冗余和混乱部分）
- 内容摘要生成
- 板块识别
- 情感分析
- 市场映射建议

**核心函数**:
```javascript
cleanTitle(title)           // 清理标题
generateSummary(content)    // 生成摘要
identifySector(text)        // 识别板块
analyzeSentiment(content)   // 情感分析
generateMarketMapping()     // 市场映射
processNewsBatch(news)      // 批量处理
```

---

### 5. ai-analyzer.js - 简报生成

**职责**:
- 生成投研简报（Markdown 格式）
- 支持晨间/晚间双版本
- 集成新闻处理结果

**简报结构**:
```
一、宏观政策和重要新闻（5 条）
二、主线复盘与资金嗅觉（3 条）
三、晚间重磅公告（4 条，仅晚间版）
四、明日推演与交易策略
```

## 🛡️ 安全设计

### API Key 保护

1. **无硬编码**：所有 API Key 通过环境变量配置
2. **.gitignore**：`.env` 文件不会被提交
3. **最小权限**：仅必需的配置才验证

### 隐私保护

1. **无用户 ID 硬编码**：由用户自行配置
2. **本地执行**：所有数据处理在本地完成
3. **可选推送**：飞书推送是可选功能

## 🎯 设计决策

### 为什么使用 OpenClaw 内置 AI？

**原因**:
1. ✅ **成本更低**：不需要额外购买 API
2. ✅ **统一管理**：OpenClaw 框架统一调度
3. ✅ **灵活切换**：支持多种模型
4. ✅ **简化配置**：用户不需要配置多个 API Key

### 为什么移除问财集成？

**原因**:
1. ⚠️ **网络问题**：当前环境无法稳定访问问财 API
2. ⚠️ **pywencai 兼容性问题**：hexin-v.js 文件缺失
3. ✅ **简化架构**：专注核心功能（新闻聚合 + 简报生成）

### 为什么晚间版跳过外盘映射？

**原因**:
1. ✅ **时效性**：晚间外盘还没开，无数据
2. ✅ **准确性**：避免使用过时数据
3. ✅ **晨间版补充**：晨间版包含隔夜外盘

## 🔍 故障排查

### 问题 1：Tavily API 配额不足

**现象**：获取新闻数量少或失败

**解决**：
1. 减少 `MAX_NEWS_PER_MODULE`
2. 升级到 Tavily 付费计划
3. 检查 API Key 是否正确

### 问题 2：标题清理不生效

**现象**：标题仍然混乱

**解决**：
1. 检查 `news-processor.js` 中的 `cleanTitle()` 函数
2. 调整分隔符列表
3. 优化截断逻辑

### 问题 3：飞书推送失败

**现象**：配置了 FEISHU_USER_ID 但未收到消息

**解决**：
1. 检查飞书用户 ID 格式（`ou_xxx`）
2. 确认 OpenClaw 飞书配置正确
3. 查看错误日志
